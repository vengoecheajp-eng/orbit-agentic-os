# Orbit Community Code of Conduct

We want Orbit to be a constructive, respectful place for people building with
AI agents. Be professional, assume good intent, and focus critique on ideas
and code rather than people.

Harassment, discrimination, threats, publishing another person's private data,
or attempting to obtain credentials through issues, skills, or pull requests is
not acceptable. Report concerns privately to the maintainer through GitHub.

Maintainers may remove comments, contributions, or access that conflict with
these expectations.
